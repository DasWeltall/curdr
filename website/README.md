# curdr product website

A buildless static site with self-hosted Gabarito, illustrative product scenarios and a copyable agent-install message. No analytics/account form. Agent documentation and installation source are distributed through GitHub because the marketing host may reject automated clients.

Run `python3 scripts/build-website.py --out artifacts/website` and host the output over HTTPS. Installation verifies the public v0.9.1 Git commit.
