# First five users

Choose five solo founders already using Hermes, including two iPhone users and one person starting without Hermes. Watch them install without coaching. Record time to first real brain dump, the exact failed step, and whether they chose a useful next action. Never collect private dump text, credentials or screenshots without consent.

Ask after an actual session:

1. What could you stop holding in your head? What did curdr add that you did not need?
2. Which proposed action would you start, defer or delete? Why?
3. Which agent interruption earned your attention? Which should have stayed silent?
4. Could you tell what the agent was doing, what had finished and what needed approval?
5. What would stop you trusting it with work tomorrow?

Prioritize repeated failures: connection/HTTPS, lost captures, unclear approvals and incorrect results before more personality or visual options. A useful release gate is all five users connecting, restoring their profile on another device and completing one real task without invented results. Count verified outcomes, not message volume. Test configured Android push separately on actual devices before claiming closed-app delivery.
