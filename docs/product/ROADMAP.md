# Product direction

Audience: solo founders carrying too many open loops. Primary promise: unload the messy thoughts, choose the few things worth doing, and get help completing them.

## Release 0.9

- [x] Original curdr mark and product website
- [x] First-run founder interview and editable explicit memory
- [x] Co-founder, brain-dump, reality-check, morning-brief and progress-review skills
- [x] Original capture history, task review and parked-idea storage
- [x] Active / Up next / Channels / Routines navigation
- [x] Routine detail/edit/test/run controls; configurable brief time and 30/60/180/300-minute checks
- [x] Actual run activity summaries, inline visualization cards and bounded workspace browser
- [x] Sorted skill library; custom skill editing and explicit local-profile installation path
- [x] Runtime model catalog/tools and honest supported-command autocomplete
- [x] Short prose messages, improved Markdown and reduced-motion-aware UI transitions

## Before calling it stable

- [ ] Test the complete install/pair/record/keyboard/approval flow on physical Android devices and a maintained live Hermes profile
- [ ] Private production signing key, reproducible release process and native store distribution
- [ ] Native push with an explicit interruption budget and notification preferences
- [ ] A reliable cross-provider memory evaluation before introducing a managed PostgreSQL backend
- [ ] Broader Hermes control API coverage as the upstream endpoints become available
- [ ] Accessibility and long-running/recovery testing across more mobile devices

Success signals are completed useful work, fewer repeatedly re-entered facts, and better decisions after brain dumps. Downloads, stars and model activity alone do not prove that the product helps.
