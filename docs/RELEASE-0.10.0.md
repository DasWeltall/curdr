# curdr 0.10.0

Brain Dump is opaque in light/dark mode. Recorded captures go directly through Make a plan (automatic transcription), with filled rounded playback controls and responsive waveforms. Reviewed items start work explicitly or save/park it.

Files lists visualizations as closed entries. New channel starts a chat-led Hermes proposal; validated output creates its focused context. Approvals expose only the scopes that Hermes advertises, preserving exact prompt/generation identity and confirming persistent rules.

Agent guidance selects the important result/decision instead of mechanically dividing long prose. Interim narration lives in activity. Web includes Gabarito, the new seed icon and a brief particle entrance (reduced-motion supported). Settings groups profile/install clearly.

First-install bootstrap can install official Hermes, invoke provider setup and prepare a verified curdr release. Existing installations use install.md with backup/rollback. The README is shorter and public build-in-public marketing is removed.

Opt-in Android notification code registers devices, persists tickets/retries, suppresses foreground duplicates, respects sleep/quiet hours and removes dead/revoked tokens. FCM/Expo owner credentials and a custom configured Android build are required. No configured-device delivery was tested or claimed. Web push is not implemented.

84 backend tests, 20 Node tests, strict TypeScript and Expo web build passed. No paid model test or private-network Hermes access was made. Fresh live provider installation remains an owner-host acceptance test.
